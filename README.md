# Юзербот для [vk.com](https://vk.com/)

Бот работает от лица владельца аккаунта: слушает User Long Poll и выполняет команды из сообщений — исчезающие
сообщения, игнор, сохранённые голосовые и кружочки, автоприём и чистка друзей, вечный онлайн.

## Запуск

1. `cp .env.example .env` и вписать `VK_TOKEN` — user-токен с доступом к `messages.*`
   (быстрый путь — https://vkhost.github.io/).
2. `docker compose up -d --build`, логи — `docker compose logs -f`.

Портов бот не публикует: он сам ходит в VK. Контейнер запускается с read-only файловой системой, без capabilities и
с лимитами на память, CPU и процессы. Поэтому на одном хосте спокойно живёт рядом с vk-bot и vk-mcp.
Настройки (игнор, доверенные, сохранённые голосовые) хранятся в томе `state`, у каждого аккаунта свои:
`state/<id аккаунта>.json`.

Перенести `data.json` со старой установки: положить его в `state/data.json` — при старте он скопируется аккаунту из
`VK_TOKEN` (первому токену), если у того ещё нет своего файла.

```
docker compose stop && docker compose cp ./data.json userbot-vk:/app/state/data.json && docker compose start
```

Доверенных можно задать и в `.env`: `TRUSTED_IDS=123,456` — числовые ID через запятую. При каждом старте они
добавляются в доверенные всех аккаунтов; `/недовер` убирает такого человека только до перезапуска.

### Несколько аккаунтов

В `VK_TOKENS` через запятую перечисляются токены других аккаунтов. Каждый работает сам по себе: свой владелец,
доверенные, игнор и сохранённые голосовые, свой long poll; неподключившийся токен бот пробует снова
раз в минуту, не мешая остальным. Команды своих же аккаунтов
выполняет только бот того аккаунта, который их написал. Команды посторонних каждый аккаунт выполняет сам: если в
беседе два аккаунта, посторонний получит два ответа.

## Команды

В чате после команды остаётся только её результат — голосовое, сообщение. Саму команду бот удаляет
(сообщение доверенного или собеседника VK разрешает удалить у всех только админу беседы — тогда оно пропадает лишь у
владельца). Ответы — список команд, ошибки, а доверенным ещё и «готово» — приходят в личку тому, кто написал команду;
владельцу — в «Избранное», и только списки, состояние `/disable` и ошибки. Посторонним бот отвечает, только если команда
пришла в личку: рассылка из беседы в личку от аккаунта владельца ведёт к ограничениям VK за спам.

Доступны всем собеседникам (`/выкл` отключает их для всех, кроме владельца и доверенных).
У каждой команды есть русские и английские названия — работают все:

| Команда | Что делает |
|---|---|
| `/хелп`, `/команды` (`/help`, `/911`, `/112`) | список команд |
| `/ид`, `/айди` (`/uid`, `/userid`) `[пользователь]` | ID пользователя |

Владельца и доверенных (доверенный командует от имени владельца):

| Команда | Что делает |
|---|---|
| `/дд`, `/удалить` (`/del`) `[N] [любое слово]` | удалить последние N сообщений владельца за сутки; со вторым словом — сначала стереть текст |
| `/и`, `/исчезни` (`/i`) `[15s\|1m\|5m\|15m\|1h\|5h\|1d] [текст]` | исчезающее сообщение; ответом на своё голосовое или стикер — переотправить их исчезающими |
| `/пп`, `/повтор` (`/repeat`) `[1-20] [текст]` | повторить сообщение с паузами |
| `/скажи`, `/эхо` (`/say`) `[текст]` | отправить текст от лица владельца (переносы строк сохраняются) |
| `/кгс`, `/копия` (`/copy`) | скопировать чужое голосовое или кружочек (ответом) |
| `/сгс`, `/гс`, `/угс [ключ]`, `/гсы` (`/sa`, `/ag`, `/ad`, `/alist`) | сохранить / отправить / удалить голосовое или кружочек, список сохранённых; `/сгс` без названия сохраняет под номером |
| `/игнор`, `/разигнор` (`/ignore`, `/unignore`) `[пользователь]` | сообщения пользователя удаляются у владельца |
| `/выкл`, `/пауза` (`/disable`) | выключить / включить общедоступные команды |
| `/автоприём` (`/autoaccept`) | вкл/выкл: принимать входящие заявки в друзья |
| `/автоотписка` (`/autounfollow`) | вкл/выкл: отменять исходящие заявки в друзья |
| `/автоочистка` (`/autoclean`) | вкл/выкл: удалять из друзей удалённых и заблокированных |
| `/онлайн`, `/вечныйонлайн` (`/online`) | вкл/выкл: держать аккаунт онлайн круглые сутки |

Автоматика работает в фоне, пока включена: онлайн обновляется раз в 4 минуты, заявки и друзья проверяются раз в
10 минут — не больше 20 действий за раз с паузами. Если VK отвечает капчей или флуд-контролем, автоматика ждёт час.

Кружочки VK не даёт загружать заново, поэтому сохраняется ссылка на оригинал: если его удалят, `/гс` ответит, что
кружочек не отправился.

Только владельца:

| Команда | Что делает |
|---|---|
| `/довер`, `/недовер` (`/trust`, `/untrust`) `[пользователь]` | сделать доверенным / убрать из доверенных |
| `/доверенные` (`/trusted`) | список доверенных |

Пользователь указывается ссылкой `vk.com/…` или `vk.ru/…`, упоминанием, ID или ответом на его сообщение (если указан
явно — ответ не учитывается).

Чужие команды — не больше 5 в минуту от одного человека, лишние молча пропускаются. Доверенный не может
заигнорировать другого доверенного.

## Разработка

```
python3.12 -m venv .venv && .venv/bin/pip install -r requirements-dev.txt
.venv/bin/pytest
.venv/bin/python -m userbot.main
```
