# Юзербот для [vk.com](https://vk.com/)

Бот работает от лица владельца аккаунта: слушает User Long Poll и выполняет команды из сообщений — жмых картинок и
голосовых, исчезающие сообщения, игнор и блокировки, сохранённые голосовые, доступ к сохрам и музыке.

## Запуск

1. `cp .env.example .env` и вписать `VK_TOKEN` — user-токен с доступом к `messages.*`
   (быстрый путь — https://vkhost.github.io/).
2. `docker compose up -d --build`, логи — `docker compose logs -f`.

Портов бот не публикует: он сам ходит в VK. Контейнер запускается с read-only файловой системой, без capabilities и
с лимитами на память, CPU и процессы. Поэтому на одном хосте спокойно живёт рядом с vk-bot и vk-mcp.
Настройки (игнор, блокировки, ассоциации, сохранённые голосовые) хранятся в томе `state`, в `state/data.json`.

Перенести `data.json` со старой установки:

```
docker compose stop && docker compose cp ./data.json userbot-vk:/app/state/data.json && docker compose start
```

## Команды

В чате после команды остаётся только её результат — голосовое, картинка, сообщение. Саму команду бот удаляет
(сообщение доверенного или собеседника VK разрешает удалить у всех только админу беседы — тогда оно пропадает лишь у
владельца). Ответы — список команд, ошибки, а доверенным ещё и «готово» — приходят в личку тому, кто написал команду;
владельцу — в «Избранное», и только списки, состояние `/disable` и ошибки. Посторонним бот отвечает, только если команда
пришла в личку: рассылка из беседы в личку от аккаунта владельца ведёт к ограничениям VK за спам.

Доступны всем собеседникам (кроме заблокированных; `/disable` отключает их для всех, кроме владельца и доверенных):

| Команда | Что делает |
|---|---|
| `/911`, `/112`, `/help` | список команд |
| `/au`, `/audio [1-4]` | жмых голосового (ответом): 1 — стандартный, 2 — сильный, 3 — слабый, 4 — робот |
| `/ma`, `/music_audio` | песня → голосовое (вложением или ответом) |
| `/d`, `/dist [1-10]` | жмых фотографии (вложением или ответом) или стикера (ответом) |
| `/n`, `/negative` | негатив фотографии (вложением или ответом) или стикера (ответом) |
| `/t`, `/text [текст]` | подпись до 200 символов к фотографии |
| `/uid`, `/userid [пользователь]` | ID пользователя |

Владельца и доверенных (доверенный командует от имени владельца):

| Команда | Что делает |
|---|---|
| `/del [N] [любое слово]` | удалить последние N сообщений владельца за сутки; со вторым словом — сначала стереть текст |
| `/i`, `/и [15s\|1m\|5m\|15m\|1h\|5h\|1d] [текст]` | исчезающее сообщение; ответом на своё голосовое или стикер — переотправить их исчезающими |
| `/repeat [1-20] [текст]` | повторить сообщение с паузами |
| `/copy` | скопировать чужое голосовое (ответом) |
| `/sa`, `/ag`, `/ad [ключ]`, `/alist` | сохранить / отправить / удалить голосовое, список сохранённых; `/sa` без названия сохраняет под номером |
| `/ban`, `/unban [пользователь]` | бот перестаёт / снова начинает реагировать на пользователя |
| `/ban_chat`, `/unban_chat` | бот перестаёт / снова начинает работать в беседе для всех, кроме владельца и доверенных |
| `/ignore`, `/unignore [пользователь]` | сообщения пользователя удаляются у владельца |
| `/disable` | выключить / включить общедоступные команды |
| `/assoc`, `/assoc_set [команда] [ассоциация]`, `/assoc_del [ассоциация]` | свои синонимы команд |
| `+s`, `-s` (`+сохры`, `-сохры`), `+a`, `-a` (`+музыка`, `-музыка`) | открыть / закрыть пользователю сохры или аудиозаписи (ответом) |

Только владельца:

| Команда | Что делает |
|---|---|
| `/trust`, `/untrust [пользователь]` | сделать доверенным / убрать из доверенных |
| `/trusted` | список доверенных |

Пользователь указывается ссылкой `vk.com/…` или `vk.ru/…`, упоминанием, ID или ответом на его сообщение (если указан
явно — ответ не учитывается).

Чужие команды — не больше 5 в минуту от одного человека, лишние молча пропускаются. Доверенный не может
заблокировать или заигнорировать другого доверенного и назначить ассоциацию команде владельца.

## Разработка

```
python3.12 -m venv .venv && .venv/bin/pip install -r requirements-dev.txt
.venv/bin/pytest
.venv/bin/python -m userbot.main
```

Для `/d`, `/au` и `/ma` локально нужны `ffmpeg` и `imagemagick`; в Docker-образе они уже есть.
